# **CALCULADORA DEL INDICE DE MASA CORPORAL (IMC)**
## **DESCRIPCION DEL PROYECTO** 

Este proyecto consiste en desarollar una calculadora de Indice de Masa Corporal (IMC) utilizando el lenguaje de programacion PYTHON.

El programa permite ingresar los datos personales del usuario, calcular su IMC y mostrar una clasificacion orientada de acuerdo con el resultado obtenido.

## **OBJETIVO**

Desarrollar un progrma que permite calcular el IMC mediante el uso de variables, operaciones matematicas, estructuras condicionales y validaciones de datos en PYTHON.

## **FUNCIONALIDADES**

- Registro del usuario.
- Caprura y validadcion de nombre.
- Captura y validadcion de apellido paterno.
- Captura y validacion de apellido materno. 
- Captura y validacion de edad.
- Captura y validacion del peso. 
- Captura y validacion de estatura. 
- Calculo automatico del IMC.
- Clasificacion del resultado. 
- Validacion de datos integrados.

## **TECNOLOGIAS UTLIZADAS**

- Python 
- Visual Estudio Code 
- Git 
- GitHub 

## **FORMULA PARA CALCULAR EL IMC**

**IMC = Peso(kg)/Estatura(m)²**
